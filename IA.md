# Registro de Uso de Inteligencia Artificial - EcoEnergy

- **Herramienta utilizada**: Gemini AI.
- **Prompts utilizados**:
  1. Configuración de entorno Django y validación de esquemas JSON.
  2. Lógica de vistas para cruce de datos y cálculo de estados de consumo.
  3. Maquetación con Bootstrap 5, herencia de plantillas y solución de error UTF-8 BOM.
  4. Explicación y generación de documentación técnica (Markdown).
- **Partes utilizadas e integradas**: Esquema de datos JSON, lógica de agregación en vistas y estructura de plantillas HTML.
- **Cambios y adaptaciones propias**: Configuración manual de rutas, verificación en consola de PowerShell, pruebas de casos de borde (404) y comprobación local del servidor.
